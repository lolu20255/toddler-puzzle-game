# UI audio

Sourced from [Kenney's UI Audio pack](https://kenney.nl/assets/ui-audio) —
**CC0** (public domain, no attribution required). Mirror used to fetch:
<https://github.com/Calinou/kenney-ui-audio>.

| File | Phaser key | Where it plays |
|------|------------|----------------|
| `click5.wav` | `ui_letter_pop` | One per letter as the celebration modal types out the matched word. Pitch is detuned per-letter to make an ascending musical reveal. |
| `switch7.wav` | `ui_match_drop` | Once when a puzzle piece is dropped on its matching shadow. |
| `switch33.wav` | `ui_celebrate` | Once when the celebration modal opens, alongside the libro-ai spoken word. |
| `rollover3.wav` | `ui_menu_tap` | MainMenu card press (Toys / Heroes / Faces). |
