Concept 01 / Minimalist

Bold A

512×512

One chunky cookie-cutter "A" in warm sunshine yellow on a deep royal-purple field. The "KIDS" sub-mark reinforces the App Store keyword without crowding the glyph. Reads cleanly at every size, from 60px Spotlight to 1024px hero.

Concept 02 / Vibrant Depth

Puzzle Pals Trio

512×512

Three claymorphic pals (sun, heart, star) huddled in the same sky-and-grass world the toddler enters on launch. Multi-color recognition lands like a flag in App Store thumbnails, and the "Pals" in the name finally has a face.

Concept 03 / Domain Metaphor

Sunny ABC

512×512

The full brand story compressed into one frame: smiling sun mascot, ABC blocks arranged like the toddler grid, sky and grass world. Most narrative of the three. Best for parents browsing the App Store on a tablet, where icons render large enough to read the scene.

How to use these files

  1. Pick a concept above and click Download PNG for a 1024 by 1024 transparent-corner file (App Store and Play Store both accept it).
  2. Drop the file into assets/icon.png in the project root.
  3. Run npm run cap:assets to regenerate every iOS and Android icon size from that single source.
  4. Rebuild with npm run build:ios or build:android.
