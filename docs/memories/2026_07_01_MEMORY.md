### The full wiring checklist for a new game (do ALL of these)
1. `src/game/scenes/GameX.js` — the scene.
2. `src/game/main.js` — `import` + add to the `scene: [...]` array.
3. `src/game/levelComplete.js` — add key to the `SCENES` rotation array
   (missing this = the game never appears in the auto-rotation after a level).
4. `src/game/scenes/MainMenu.js` — add a `GAMES` entry (label/scene/color/
   colorDark/darkHex/iconKey/free).
5. `src/game/scenes/Boot.js` — bake a procedural menu icon in a `generate*`
   method called from `create()`'s `proceed()`, and/or `load.image(...)` any
   art in `loadGameAssets()`.
6. `src/game/itemNames.js` — add the pack to `ITEM_NAMES.en` + `.es`; add to
   `WORD_ONLY_PACKS` if the audio should be the bare word (no letter spelling).
7. `npm run generate:audio` — writes `public/audio/levels/<lang>/<pack>/*.mp3`
   (skips existing; hits the libro API). Bundled MP3s = zero runtime API spend.

## Gotchas worth remembering

- **Asset-key letters cap at `a`–`j`.** `parseAssetKey` (levelAudio.js) and
  `nameForAssetKey` (itemNames.js) both use `^asset_(.+)_([a-j])$`. A pack can
  hold **at most 10 items**. That's why Opposites is 5 pairs (10 icons), not 6.
- **Texture pack name must equal the audio pack name.** `asset_<pack>_<letter>`
  → audio at `/audio/levels/<lang>/<pack>/<letter>.mp3` and `ITEM_NAMES[..][pack]`.
  Opposites textures are `asset_opposites_*` (not `asset_opp_*`) for this reason.
- **`continue` is illegal inside `forEach`** (build error). Use `return`.
- **gpt-image-1 transparency:** even with `background:'transparent'` it will bake
  an opaque backdrop/glow unless the prompt explicitly forbids it ("clean cut-out
  sticker … no backdrop, no glow, no vignette, no gradient, no ground shadow,
  pure alpha"). The reddish "glow" the Read tool shows is actually alpha-0 RGB —
  confirm cleanliness by compositing over a colour with PIL, not by eyeballing
  the Read preview. Workflow: generate 1024² transparent (medium quality ≈ $0.04),
  then `sips -z 256 256` in place to match the fruits pack.
- **Animal sounds are TTS onomatopoeia** ("Moo!", "Woof!") via the new
  `animal_sounds` pack — no external sound files. Fits the existing pipeline and
  is bilingual for free.

## Verification harness (scratchpad — reusable)

`scratchpad/cdp-shot.mjs` drives headless Chrome over the DevTools Protocol
(Node 24 has global `WebSocket`/`fetch`, no playwright needed):
1. `python3 -m http.server 8123` inside `dist/` (after `npm run build`).
2. Bypass onboarding: `localStorage['CapacitorStorage.onboardingComplete']='true'`
   then reload.
3. `window.__phaserGame` is exposed (PhaserGame.vue) → `.scene.start('GameX')`.
4. `Page.captureScreenshot`.
Caveat: headless backgrounds throttle rAF, so Phaser tween/`delayedCall` timers
lag in wall-clock — a screenshot can catch a scene "mid-advance". Score/state
increment synchronously on tap, so verify those via `Runtime.evaluate`, not by
waiting for the timer-driven round change.
