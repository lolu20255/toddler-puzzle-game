# 2026-09-29 session

Goal: full bug/audio audit, fix everything found, premium animated splash
(ReadLens-style), menu background music. Four read-only audit agents covered
audio, GameA-H, GameI-P + menu/settings/overlays, and the ReadLens splash.

## Business-critical fix

- `src/config.js` had `FORCE_PREMIUM = true` committed since d20d335. Every
  build since then unlocked all 16 games and never showed the paywall. Now
  `false`. **Check whether a shipped App Store build carried it.**

## Bugs fixed

- **Scene state leaked across visits (soft-locks).** Phaser reuses scene
  instances; per-run state lived in constructors. Every game scene (A-P) now
  resets it in `init()`. Before: a pack played twice never completed; GameA/B/C
  threw in dragend; M/N ignored all taps on revisit; J/K/L/O ended on a blank
  screen; rotation restarts inherited finished state.
- **Plain tap auto-matched the wrong piece** (A-G, P): dragend used a stale
  `animalDragged` closure. Now it judges the released piece
  (`isAnimalOnBase(gameObject.name)`).
- Snap tolerance was 10 physical px; now `SNAP_TOLERANCE = 0.05` of the short side.
- `pieceDrop.js`: pieces squeezed through a wall or the floor are respawned at the top.
- `celebrate.js`: ReferenceError (`praiseAudio`) in the no-audio fallback left
  the child on a dimmed modal forever; now wrapped with a guaranteed dismiss.
  Overlapping spellings on fast matches are stopped, every await re-checks
  `modal.scene`, and a stale `ended` flag no longer starts the praise early.
- Speech is stopped on every scene shutdown via one permanent listener per
  scene (`main.js silenceSpeechOnSceneExit`); the old `once` hook only worked on
  a scene's first visit.
- `levelAudio.js`: in-flight load dedupe (orphaned Audio elements), timeout
  cleared, relative URLs.
- GameN animal name played twice per tap; GameH words overlapped; GameH cards
  drifted left on each miss; K/L/M/O tiles drifted on repeated wrong taps.
- Auto-rotation after a level could send free users into locked games.
  `FREE_SCENES` + `isScenePlayable()` in `levelComplete.js` (MainMenu reads them).
- Taps on Vue overlays (Paywall/Onboarding/RateUs) fired Phaser objects under
  them: `input.windowEvents: false` in `main.js`.
- Back button spam queued several MainMenu starts; now disables itself.
- Settings "Premium Active" card opened an ungated external URL (Kids Category
  1.3); removed. Premium card text is fit to width.
- Android hardware back now returns to the menu (was a dead event).
- App backgrounding stops TTS and pauses music (`native.js watchAppLifecycle`).
- Boot now awaits `settings.load()` (memoised) and explicitly loads fonts.
- Emoji replaced where they rendered as "?" boxes in the iOS 26.3 simulator:
  menu padlock (vector), onboarding globe + flags (SVG). Paywall/Settings crown
  still use emoji (fine on real devices per earlier sessions).

## Premium features

- **SplashIntro.vue**: flat `#6a5ae0` native splash (assets/splash\*.png, config
  `backgroundColor` + `SplashScreen.backgroundColor`) hands off to an animated
  overlay: four SVG puzzle pieces fly in and snap, smiley pops + winks, sparks,
  "ABC KIDS / Puzzle Pals" letter bounce, localized tagline. Holds until
  `current-scene-ready` or `onboarding:open` (min 2.6 s, max 7 s). The overlay
  hides the native splash, not `native.js` any more. All three colours must match.
- **Edge-to-edge iOS** (`src/game/viewport.js`): status bar overlays the web
  view; `#game-container` is offset by `env(safe-area-inset-top)`; the strip is
  repainted per scene from the canvas's top pixel (`snapshotPixel`) and the
  status bar text flips light/dark. Android unchanged (no inset reported).
  Canvas size now comes from the container (`gameViewportSize()`), also in
  responsive.js.
- **Menu music** (`src/services/music.js`): CC0 "Yippee !" (Loyalty Freak
  Music, ukulele-style happy folk, 40-bar loop with a 1.2 s crossfade) in
  `public/assets/audio/music/menu_theme.m4a`. The first pick, "Cute Tune"
  (music box), was rejected by the owner as too sleepy, then "Funky Pop" was tried: prefer upbeat, modern,
  clear-beat tracks. Audition page with 6 CC0 candidates was built in the
  scratchpad; the track is streamed through a
  MediaElementSource + gain on Phaser's AudioContext (decoding it would cost
  ~50 MB PCM). Plays on MainMenu + Settings, fades out in games, resumes where
  it left off. `musicEnabled` setting + Music toggle in Settings.
- Fonts bundled via `@fontsource/fredoka` + `@fontsource/bruno-ace-sc`; the
  Google Fonts CDN link is gone (offline-safe, no third-party request).
