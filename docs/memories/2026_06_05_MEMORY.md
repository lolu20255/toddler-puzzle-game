## Falling puzzle pieces (physics) — all matching games

Switched the whole game from **Arcade to Matter.js** physics (Matter is bundled
in Phaser, no install). Reason: Arcade only has axis-aligned rect/circle bodies
and its separation stacks poorly, so pieces visibly overlapped. Matter's solver
guarantees solid bodies never intersect and stacks cleanly.

- `src/game/main.js`: `physics.default: 'matter'`, `matter.gravity.y: 1`
  (Matter's native earth-normal gravity). Old arcade config removed. Nothing
  else in the app used arcade (`this.physics`), so the swap was safe. NOTE:
  GameI has `item.body` but that's a named display object, NOT a physics body.
- `src/game/pieceDrop.js` rewritten for Matter. `dropPieces(scene, pieces)`:
  - `scene.matter.world.setBounds(0,0,w,h,128,true,true,false,true)` — floor +
    side walls, **top open** so pieces can fall in from above the screen.
  - Each piece: `scene.matter.add.gameObject(piece, { shape: { type:
    'rectangle', width: displayWidth*0.8, height: displayHeight*0.92 } })`
    (body sized to the visible art, trimming transparent frame padding),
    `setBounce(0.45)`, `setFixedRotation()` (stay upright, no spin/tip).
  - Spawn: shuffled lanes, staggered negative-y, `piece.setPosition(...)`.
  - Drag: `dragstart` → `setStatic(true)` (follows finger, ignores gravity);
    `dragend` → if NOT locked `setStatic(false)` + re-`setFixedRotation()`;
    locked pieces stay static frozen on the shadow. "Locked" = the scene's
    `disableInteractive()` nulled/disabled `obj.input`.

Key Matter facts confirmed in `node_modules/phaser` source:
- Matter Transform component's x/y SETTERS call `Body.setPosition`, so the
  scenes' existing `gameObject.x = dragX` drag handler moves the body unchanged
  (no helper 'drag' listener needed).
- `matter.add.gameObject(go, { shape })` mixes the Matter components onto the
  existing Image and applies the shape via `setBody`.
- `setFixedRotation` lives in the Transform component; `setBounce` in Bounce;
  `setStatic` in Static.

Tuning knobs in pieceDrop.js: `BOUNCE` (0.45), `BODY_FILL_X` (0.8),
`BODY_FILL_Y` (0.92). Lower fills = pieces nestle closer.
