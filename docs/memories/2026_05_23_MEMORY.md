## Architectural decisions (and divergences from Coinvertor)
- **No Chrome-extension branch** — simpler `platform.js`; services import
  Capacitor plugins statically and guard calls with `isNativePlatform()`.
- **Vite env vars** (`import.meta.env.VITE_*`) instead of `process.env.VUE_APP_*`.
- **Privacy-safe analytics** — `analytics.js` is a local-only abstraction
  (no Amplitude / Firebase / GA), because this is a kids app. Wire a
  COPPA-compliant endpoint in `dispatch()` later if needed.
- **No AdMob, no ATT** — both carry high rejection risk in the Apple Kids
  Category / Google Families program.
- **Hardware back button** is captured and emitted on `EventBus` instead of
  exiting the app — prevents accidental exits by toddlers.
- **Vite prod config already has `base: './'`** — no Capacitor-related Vite
  changes were needed.
